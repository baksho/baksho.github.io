How it works

What this page is, and is not. It is a small, exact toy: a few dozen cells, a table with one number per cell and action, and no neural network. It shows the ideas behind value iteration and Q-learning. It does not show how these methods are used on large problems, where the table is replaced by a learned function.

The world

The agent stands on one cell and picks one of four moves: up, right, down or left. Moving into a wall or off the edge leaves it where it is. With the slip chance set to p, the chosen move happens with probability 1 − p, and with probability p/2 each the agent instead goes to one of the two sides. Every move costs a small amount. Entering the goal gives +1 and entering the pit gives −1; either one ends the episode. Walls cannot be entered.

This is a Markov decision process: the result of a move depends only on the current cell and the move, not on the earlier path.

What a value is

The value V(s) of a cell is the total reward you can expect from there on if you always play the best moves, where a reward k steps ahead counts with weight γk. The Q-value Q(s, a) is the same quantity if you first make move a, then play the best moves. The value is the best Q-value, and the arrow points to the move with the best Q-value. If several moves tie, several arrows are drawn; if all four tie (for example before anything has been learned), no arrow is drawn.

Value iteration

Value iteration is given the rules of the world, meaning the probabilities and the rewards. It starts with every value at 0 and repeats a sweep: for every cell, replace the value by the best one-step lookahead using the previous values.

Vnew(s) = maxa Σs' P(s' | s, a) · [ r + γ V(s') ]

After k sweeps the values are the best you can do when looking k moves ahead, so good news spreads outward from the goal one cell per sweep. For γ < 1 the largest change per sweep shrinks steadily (the update is a contraction, see Sutton and Barto, section 4.4), and the page stops once it falls below 10−6. Hover over a cell to see the four lookahead values behind its arrow.

Q-learning

Q-learning is not told the rules. A single agent walks around, and after every move from cell s with action a, landing in s' with reward r, it nudges one table entry toward a new target:

Q(s, a) ← Q(s, a) + α · [ r + γ maxa' Q(s', a') − Q(s, a) ]

If s' is the goal or the pit, the target is just r. The agent picks a random move with probability ε and otherwise the best move it currently knows (ε-greedy). Because the target uses the best next move whatever the agent actually does next, Q-learning learns the values of the best strategy even while exploring. Watkins and Dayan proved that the Q-values converge to the optimal ones with probability 1 under conditions on how often every action is tried and on a learning rate that shrinks over time. This page uses a constant α instead, so the estimates keep jittering (see below). An episode that has not ended after 200 moves is cut off and restarted from the start cell.

The chart for Q-learning compares its values with the optimal values, which the page computes with value iteration in the background. The agent never sees them.

What to try

  • Classic 4×3 with γ = 1. This is the textbook world (0.8 / 0.1 / 0.1 moves, cost 0.04). Value iteration gives 0.705 at the start cell, 0.812, 0.868 and 0.918 along the top row, and 0.388 in the bottom-right corner next to the pit. I compared nine cells with the values I remember from Russell and Norvig's textbook and they agree to three decimals; please check them against your copy of the book. With the default γ = 0.95 the start value is 0.501 and the sweeps stop after 25.
  • Discount. On the classic world, γ = 0.5 gives a start value of about −0.05, against 0.50 at γ = 0.95, because a far-away goal hardly counts.
  • Slip chance on “Cliff edge”. With slip 0, the best route runs along the row right above the pits. With slip 0.2 (cost 0.04, γ = 0.95), the best route moves one row further up, away from the pits, and the start value drops from about 0.43 to about −0.01.
  • Learning rate. On the classic world, I ran Q-learning for 300,000 moves with ε = 0.2 from five random seeds. With α = 0.1 the largest value error ended between 0.17 and 0.25 and 7 to 9 of the 9 arrows were optimal. With α = 0.02 the error ended between 0.02 and 0.08 and all 9 arrows were optimal in every run. The arrows that were wrong with α = 0.1 lost between 0.03 and 0.10 in value, so they were close calls.
  • Different random seeds. Q-learning only visits cells its random path reaches, and early arrows can be wrong. Restart with another seed to see how much the early path depends on luck.
  • Paint your own world, for example a wall that blocks the short route, and compare how the two algorithms react.

Limits

  • The table has one entry per cell and action, so this does not scale to large problems.
  • Value iteration here is given the true rules and is not simulating an agent; Q-learning learns without them. They are compared on the same world, but they are not doing the same job.
  • Q-learning runs for at most 300,000 moves, and a constant α leaves some noise at the end.
  • Results are for this made-up world and these settings. Other worlds can behave differently.
