Learning Chess by Self-Play

The agent starts knowing the rules of chess and nothing else: it thinks every piece is worth zero. It plays full games against itself, learns from who wins, and slowly works out how much each piece is worth. Watch the values settle, then play it yourself.

Play against it

It plays with whatever it has learned so far, so give it a minute of training first. Pawns promote to queens.

How it works

Honest expectations. This is a small learner in a browser tab. It learns sensible piece values and gets clearly better than a random mover, but it stays a weak chess player. It does not learn strategy.

What is learned

Five numbers: the value of a pawn, knight, bishop, rook and queen. A position's score is your pieces' values minus the opponent's. The agent picks moves with a short look-ahead search that uses this score.

How it learns

It plays itself. After each game it nudges its five numbers so that the score of each position agrees better with the score of the next one, and ultimately with how the game ended (a method called TD-leaf(λ)). Pieces that tend to be on the winning side get a higher value.

One shortcut you should know about

Early games between a clueless agent rarely end in checkmate. Games that run past 120 moves are therefore scored by who is ahead in material instead of as a draw. That is a hint built in by me, not something the agent discovered, and it nudges it towards valuing material.

What the bars mean

Only the ratios matter, so the values are shown with a pawn as 1. Early on the pawn's value is near zero and the ratios jump around; they settle as games accumulate. They will not match 3, 3, 5, 9 exactly.

The "wins against a random mover" number

Every 200 games the agent plays 30 games against a mover that picks random legal moves, alternating colours, learning off. The figure is wins plus half the draws, out of 30, so it is noisy by roughly ±0.09.
